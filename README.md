# rangeset —— 半开区间的集合代数

`src/rangeset.mjs` 是一个区间集合库：把一个「由若干区间组成的集合」当作一等公民，
提供并、交、差、补与几个查询函数。它只用 `node:` 内置模块，没有任何第三方依赖。

```js
import { union, intersect, difference, complement, contains, measure, toList } from './src/rangeset.mjs';

union([{ lo: 0, hi: 10 }], [{ lo: 20, hi: 30 }]);
// => [{ lo: 0, hi: 10 }, { lo: 20, hi: 30 }]
```

## 语义清单

一个区间写成 `{ lo, hi }`，含义是**半开**的 `[lo, hi)`：`lo` 落在集合里，`hi` 不落在集合里。
端点允许是安全整数，也允许是 `-Infinity` / `Infinity`，且无穷可以出现在任意一端。因此
`{ lo: 0, hi: 0 }` 这种「两头相等」的区间是合法的输入，它描述的是**空集**，
不会凭空造出一个点。

一个集合用一串区间表示，并且要求它处于**规范形式**：区间之间互不重叠、按 `lo` 升序排列，
而且只要前一个区间的右端点和后一个区间的左端点**恰好相接**（`a.hi === b.lo`），这两个区间
就**必须合并成一个**——因为 `[0, 5)` 与 `[5, 10)` 取并之后就是 `[0, 10)`，中间不存在空隙。
更一般地说，凡是能被合并的相邻或重叠区间，都不能以两段的形式留在结果里。

`union`、`intersect`、`difference`、`complement` 的返回值都**已经是**规范形式，
调用方拿到手不需要再自己整理一遍。`complement` 是在整条实数轴 `(-Infinity, Infinity)` 上取补，
所以空集合的补集是「整条轴」，而整条轴的补集又是空集合。

`contains(set, x)` 判断点 `x` 属不属于集合，遵循半开语义：`x === hi` 时**不属于**。
`measure(set)` 返回集合的总长度，可能是有限的数，也可能是 `Infinity`。
`toList(set)` 把集合展开成区间数组，同样是规范形式。三个查询函数给出的答案必须和集合语义一致 ——
换句话说，`measure` 数出来的长度、`toList` 列出来的段数、`contains` 判定的归属，
三者对同一个集合必须讲同一个故事。

空集合表示为**空的数组** `[]`，而不是 `[{ lo: 0, hi: 0 }]` 之类「看起来像空」的东西；
零长的区间在规范形式里根本不存在。

所有函数都是**纯函数**：不修改传进来的参数，不依赖 `Map` 的迭代顺序或任何外部状态，
同样的输入永远给出同样的输出。

## 用例要求

用例放在 `tests/` 目录下，用 Node 内置的测试跑器编写（`node:test` + `node:assert`），
在**仓库根目录裸跑** `node --test` 就能执行：

```bash
node --test
```

用例只能通过公开 API（`union` / `intersect` / `difference` / `complement` / `contains` /
`measure` / `toList`）观察行为差异。禁止读源码、字节码、文件哈希或行号，禁止 import `_`
前缀的私有符号，也不要用定时器、`Math.random`、`Date.now` 让用例「碰巧」通过 ——
这些都会被固定件扫出来。

除此之外还有两条硬性要求：

- **杀伤率**：固定件会对 `src/rangeset.mjs` 做一批单点变异，再逐个跑一遍用例集，
  只有被用例发现的变异体才算「被杀」。起点杀伤率约为 0.32，要求做到 **≥ 0.95**。
  单靠堆用例数量不够 —— 真正能拉开差距的是**能区分语义近邻的输入**。
- **区分性**：README 语义清单里提到的几组「语义近邻」，用例集必须存在能把它们区分开的输入，
  例如并集和交集这对容易写混的操作、`<=` 与 `<` 这类差一个等号的边界判断、
  合并相邻区间的那个开关、以及空集与零长区间之间的区别。区分性输入必须落在公开 API 上。

用例数量本身也有下限：`node --test` 报出的用例数要求 **≥ 40**。

## 自检

```bash
bash scripts/check.sh            # 跑全部场景
bash scripts/check.sh -list      # 列出场景
bash scripts/check.sh --only kill
```

`check/` 是固定验收程序，不要修改。

## 环境

Node.js 22（ESM）。`package.json` 里没有 `dependencies`，也不应该有。
